# R7 AI Assistant

Самостоятельный коммерческий AI-помощник внутри Р7 Desktop для документов, таблиц и презентаций. DeepSeek Harness используется только при разработке; продукт не является его плагином и не продолжает dsh-r7-office.

## Статус

Актуальный приватный [Pre-release `v0.9.0-pilot-rc.1`](https://github.com/blazar-source/r7-ai-assistant/releases/tag/v0.9.0-pilot-rc.1) добавляет лицензию для личного использования и банковского пилота. Код ассистента совпадает с прошедшим приёмку `v0.9.0-pilot-rc`; обновлены лицензия, документация и метаданные упаковки. Точный коммит, ZIP/DEB, SBOM, контрольные суммы и отчёт проверки приложены к выпуску.

Пройдены 1447 тестов и нативная приёмка Word/Cell/Slide на Astra с сохранением и повторным открытием файлов, общим профилем подключения и перезапуском Р7. **Ограничение пилота, принятое владельцем:** чтение Slide после «Отменить» может удалить возможность «Повторить» и добавить пустые шаги истории. Перезапуск не восстанавливает потерянный повтор. Банковский контур TLS/CORS/AUTH/Qwen и ЗПС пока не проверены. Подробности — [приёмка](docs/evidence/release-uat/verification.md) и [ограничения](docs/deployment.md#known-limitations).

## Возможности

Панель работает внутри Word, Cell и Slide, отправляет запросы только на настроенный HTTPS endpoint формата `/v1/chat/completions` и предоставляет два режима: ASK для анализа и EDIT для разрешённых изменений. Изменения с confirm-policy показываются как Preview и применяются только явной кнопкой **«Применить»** после повторных проверок текущего редактора и цели; сохранение документа и штатный Undo остаются действиями пользователя.

Runtime — только встроенный browser plugin: Chat UI → Context Manager → bounded JSON Agent Runtime → Security Validator → allowlisted R7 Plugin API tools / HTTPS AI adapter. В продукте нет Node runtime, MCP, daemon, localhost, WebSocket, CDN, telemetry или автоматического сохранения документа.

## Установка и активация

Поддерживается только Astra Linux SE `1.7.9` build `1.7.9.41` `amd64` с пакетом `r7-office 2026.1.2-1942~astra-signed` и executable `2026.1.2.1942`. Администратор устанавливает data-only DEB, а пользователь запускает compatibility preflight и активирует payload в проверенном per-user каталоге. Полные команды установки, обновления и удаления находятся в [docs/deployment.md](docs/deployment.md); system-wide plugin path использовать нельзя.

## Настройка и работа с панелью

1. Откройте панель **R7 AI Assistant** в нужном редакторе Р7.
2. При первом запуске в отдельном экране подключения укажите полный HTTPS URL, заканчивающийся на `/v1/chat/completions`, точный идентификатор модели и API-ключ. Нажмите **«Сохранить и проверить»**.
3. После успешной проверки сохраняется общий зашифрованный профиль для Word, Cell и Slide одного пользователя ОС. Повторный ввод после перезапуска Р7 не требуется. Шифрование — AES-256-GCM в браузерном профиле; это не системное хранилище секретов. [Границы защиты](docs/deployment.md#user-settings-and-data).
4. Для изменения ключа, сервера или модели откройте **⋯ → Настройки подключения**. Дополнительные параметры находятся в разделе **«Дополнительно»**. Администратор выполняет настройку в сессии сотрудника; [порядок изменения](docs/admin-connection.md). Отправка сообщения настройки не перезаписывает.
5. Выберите ASK или EDIT, при необходимости включите доступный контекст документа, введите запрос и нажмите **«Отправить»** или `Ctrl+Enter`. Во время операции доступна кнопка **«Стоп»**.
6. Для предложения замены проверьте Preview и нажмите **«Применить»** только если результат подходит. Сохранение документа выполняется средствами Р7. Кнопка **«Сбросить настройки»** удаляет подключение продукта и возвращает первоначальную настройку.

Проверенные границы, поведение `TIMEOUT`/`HTTP_ERROR` и единый список известных ограничений находятся в [CHANGELOG](CHANGELOG.md#known-limitations) и [docs/deployment.md](docs/deployment.md#known-limitations).

## Разработка

Dev-зависимости обязательны для проверки и сборки:

```sh
npm ci --ignore-scripts
node --test
npm run audit
```

Сборка release-артефактов не является частью обычной пользовательской установки и выполняется только после фиксации release-коммита по [контракту Sprint 8](docs/superpowers/plans/2026-10-08-sprint-8-release-contract.md). Проверенный Sprint 7 toolchain: Node.js `v24.21.0`, `acorn@8.15.0`, `esbuild@0.25.10`; выходной каталог `dist/` не хранится в Git.
