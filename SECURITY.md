# Сообщение о проблемах безопасности

Текущая поставка — пилотный Pre-release `0.9.0-pilot-rc.1` для конфигурации из [инструкции установки](docs/deployment.md). Это не сертификация для банковского контура или ЗПС.

## Канал сообщения

Репозиторий приватный. Участники с доступом сообщают о возможной уязвимости сопровождающим через Issue **в этом приватном репозитории**; он будет виден всем участникам с соответствующим доступом. Если описание нельзя раскрывать всему составу участников, сначала обратитесь к ответственному администратору банковского пилота по принятому в организации закрытому каналу. Пользователи без доступа также обращаются к администратору пилота.

Не публикуйте сведения об уязвимости в публичных репозиториях. Отдельный публичный адрес security-поддержки и гарантированный срок ответа пока не установлены.

Укажите версию, платформу, минимальное воспроизведение на тестовых данных и предполагаемое влияние. Не присылайте API-ключи, рабочие документы, персональные данные, заголовки авторизации или полный профиль Р7.

## Границы продукта

- Данные запросов и результаты чтения могут передаваться настроенному AI-серверу. Допуск данных и сервера определяет организация.
- Ключ локально зашифрован, но CryptoKey находится в том же браузерном профиле. Это не системное хранилище секретов.
- Действия модели ограничены схемами и каталогом инструментов. Произвольный код модели не выполняется.
- В EDIT большинство правок выполняются по запросу без дополнительной кнопки подтверждения.
- Дефект Slide Undo → ASK → Redo не исправлен и принят владельцем только для пилота.
