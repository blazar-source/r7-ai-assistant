# Изменение подключения администратором

Для пилота администратор настраивает плагин через удалённое подключение **в рабочей сессии сотрудника**. Профиль общий для Word, Cell и Slide одного пользователя ОС. Изменение в отдельной учётной записи администратора не меняет настройки сотрудника.

1. Дождитесь завершения текущего задания ассистента.
2. Откройте панель **R7 AI Assistant** в любом из трёх редакторов.
3. Откройте меню **⋯ → Настройки подключения**.
4. Замените API-ключ, адрес сервера или модель. Если меняете только модель или адрес, повторный ввод сохранённого ключа не нужен. Поле ключа маскируется. Тайм-аут и параметры генерации находятся в разделе **«Дополнительно»**.
5. Нажмите **«Сохранить и проверить»**. Новый профиль сохраняется с шифрованием после успешной проверки подключения. При ошибке проверки прежний сохранённый профиль остаётся действующим; исправьте введённые данные и повторите проверку.
6. Убедитесь, что панель вернулась к чату со статусом **«Готово»**. Остальные открытые панели новой версии подхватят изменения в состоянии ожидания, при получении фокуса или перед следующим запросом. Выполняющееся задание сохраняет свои исходные настройки до завершения.

Если другая панель уже сохранила изменения, устаревшая форма не перезапишет их. Нажмите **«Загрузить актуальные настройки»**, затем повторите нужное изменение.

Для смены ключа не требуется сбрасывать профиль, переустанавливать плагин или закрывать документы. **«Назад»** отменяет несохранённые правки формы. **«Сбросить настройки»** удаляет действующее подключение и возвращает экран первоначальной настройки.

Это административная процедура для пилота, а не разграничение прав внутри плагина: пункт **«Настройки подключения»** доступен и сотруднику в его сессии. Отдельная роль администратора, запрет изменения пользователем и централизованная выдача профилей пока не реализованы.
