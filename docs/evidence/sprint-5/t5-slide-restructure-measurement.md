# Sprint 5, T5 — измеренная поверхность перестройки презентации (2026-10-07)

**Зачем.** T5 («редактирование/перестройка существующей презентации») обязан ответить замером на открытые
вопросы плана §10.1–10.4 и §10.8, прежде чем проектировать контракт. Первая попытка делегированного замера
дала **пустые** результаты (`{"type":"undefined"}`, ни одного значения) — она отброшена целиком, а замер выполнен
заново и проверен на непустоту. Ниже — только то, что реально измерено.

**Стенд.** Astra SE 1.7.9.41 + Р7 **2026.1.2-1942** (целевой); живой редактор презентации, одноразовая колода
(5 слайдов: 0/1/3 на layout `"306"`, 2/4 на `"219"`; слайд 3 несёт текст `WHOLE_OBJECT_TEXT`, слайд 4 —
`SPRINT1 unchanged Slide fixture`). Ничего не сохранялось.

## 1. Отпечаток слайда — рабочая мера «не тронут» (§10.8)

Отпечаток = `{ index, layoutLength, layoutHead, shapes, texts[], jsonLength, jsonHead }`, где `texts` — тексты
объектов, а `jsonLength` — длина `slide.ToJSON()`.

| контроль | результат |
| --- | --- |
| два чтения подряд **без мутации** | отпечатки **совпадают** для всех пяти слайдов (например, слайд 3: `jsonLength=32115`, `texts=["WHOLE_OBJECT_TEXT",""]` в обоих чтениях) |
| длины JSON по слайдам | 34 762 / 34 763 / 31 347 / 32 115 / 29 383 — различают слайды |

**Вывод:** отпечаток **стабилен** и годится как доказательство «остальные слайды не изменились». Сравнивать
надо значения, а не тождество обёрток (оно нестабильно — измерено в T2/T3).

## 2. `slide.Duplicate()` (§10.1)

| факт | измерение |
| --- | --- |
| возврат | **объект** (`typeof object`), не boolean |
| число слайдов | 5 → 6 |
| текущий слайд | **не меняется** (0 → 0) |
| где оказалась копия | **в КОНЦЕ** (индекс 5), а не рядом с источником (источник — 3) |
| копия = источник? | layout **совпадает** (`"306"`, 11 200), число объектов совпадает (2), тексты совпадают (`WHOLE_OBJECT_TEXT`), но **`jsonLength` копии 33 948 против 32 115 у источника** — JSON НЕ идентичен |
| остальные слайды | отпечатки слайдов 0–4 **не изменились** |

**Следствие.** Инструмент дублирования может доказывать: счётчик +1, копия в конце с layout/числом
объектов/текстами источника, остальные слайды не тронуты. **Заявлять побайтовую идентичность копии нельзя** —
измерено обратное.

## 3. `slide.MoveTo(index)` (§10.2)

| факт | измерение |
| --- | --- |
| возврат | **boolean** (`true`), не объект |
| перенос 4 → 0 | `GetSlideIndex()` по индексу 0 = **0**, число слайдов не изменилось, текущий слайд **не изменился** (0 → 0) |
| доказуемость результата | тексты до `["","","","WHOLE_OBJECT_TEXT","SPRINT1 …","WHOLE_OBJECT_TEXT"]`, после `["SPRINT1 …","","","","WHOLE_OBJECT_TEXT","WHOLE_OBJECT_TEXT"]` — перенесённый слайд действительно стоит на целевом индексе |
| отпечатки после переноса | отпечаток бывшего слайда 4 (`layoutLength=10552`, `jsonLength=29383`) теперь на индексе 0 — перенос **отслеживается по отпечаткам**, а не по позиции |
| **вне диапазона** (0 → 99) | `MoveTo` вернул **`false`**, документ не изменился; последующее обращение по индексу 99 даёт `null` |
| **тот же индекс** (0 → 0) | вернул `true`, ничего не изменилось (идемпотентно) |

**Следствие.** Перенос доказуем: `MoveTo` вернул `true`, число слайдов не изменилось, отпечаток перенесённого
слайда находится на целевом индексе, а набор отпечатков остальных слайдов сохранён. `false` — это **известный
отказ** (аргумент вне диапазона), а не неопределённость.

## 4. `GetPlaceholder()` — роль объекта НЕ установлена (два замера расходятся)

| замер | слайд | объект 0 | объект 1 |
| --- | --- | --- | --- |
| контроллер | 0 | `{"Placeholder":{"Id":"1750","idx":null,"type":3}}` | `{"Placeholder":{"Id":"1766","idx":"1","type":13}}` |
| контроллер | 3 | `{"Placeholder":{"Id":"1623","idx":null,"type":3}}` | `{"Placeholder":{"Id":"1640","idx":"1","type":13}}` |
| независимый делегированный замер | 0 | `type 15`, `idx=null` | `type=null`, `idx="1"` |

**Вывод (исправлено после второго замера).** Оба замера реальны, но их значения **не совпали**, и ни один не даёт
семантического имени «заголовок/тело». Поэтому адресация по роли **не вводится и не используется** (§15.6):
T5 адресует объекты через `objectOrdinal`, а «не тронутость» доказывает отпечатками. `Id` уникален для
экземпляра и ролью не является. Чтобы закрыть вопрос, нужен один замер, читающий на ОДНОЙ колоде и сам объект, и
его `ToJSON()`, и объясняющий расхождение.

**Уточнение по отпечатку (из того же второго замера).** Длины и префикса JSON **недостаточно**: точечная правка
текста может не изменить префикс. Содержательную часть отпечатка несут **тексты объектов**, и именно они ловят
изменения; `jsonLength`/`jsonHead` — вспомогательный сигнал. Второй замер также подтвердил, что точечная правка
не изменила ни другие объекты целевого слайда, ни остальные слайды (на обоих стендах).

## 5. Чего эти замеры НЕ показывают

* **Точность частичной правки** (§10.3) не измерялась: T5 работает целыми объектами, как и требует §6.0.7.
* Визуальный результат переноса/дублирования (порядок на экране, анимации) не проверялся; доказаны структура и
  тексты.
* Сохранение и повторное открытие (Save/reopen) — предмет exit gate.
* Поведение `Duplicate`/`MoveTo` на колодах с **заметками/скрытыми слайдами** не измерялось: колода простая.
* Расхождение Astra ↔ Windows для этих операций **не измерено в этом прогоне** (целевой стенд — Astra; Windows
  должен быть перепроверен при приёмке T5).

## 6. WHAT THIS ENABLES / WHAT IT FORBIDS

| возможность | вердикт | основание |
| --- | --- | --- |
| `duplicate_slide` с доказуемым результатом | **можно** | счётчик +1, копия в конце с layout/объектами/текстами источника, остальные отпечатки не изменились; **без** заявки на побайтовую идентичность |
| `move_slide` с доказуемым результатом | **можно** | возврат `true`, счётчик неизменен, отпечаток перенесённого слайда на целевом индексе, остальные сохранены; `false` = известный отказ по аргументу |
| «изменены только целевые слайды» | **можно** | отпечатки стабильны (контроль) и перечисляются по слайдам |
| адресация объекта **по роли** | **не установлено — не используется** | два замера дали разные `type` (3/13 против 15/null) и ни один не даёт семантического имени «заголовок/тело» (§4) |
| адресация объекта по `Id` между слайдами | **нельзя** | `Id` уникален для экземпляра |
| побайтовая идентичность дубликата | **нельзя** | `jsonLength` копии отличается от источника |

**Артефакты:** проба `.local/sprint5/t5-measure.js`, сырой ответ `t5-measure-astra.json` (тип ответа проверен
как `object`, а не `undefined`).
