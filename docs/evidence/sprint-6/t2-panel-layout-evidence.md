# Sprint 6 / T2 — evidence: панель как flex-колонка с единственным скроллом и закреплённым композером

## 1. Что менялось

`src/ui/styles.css` (7/2), `src/ui/view.js` (3/1) и `tests/unit/view.test.js` (45/0). Никаких изменений рантайма,
моста, реестра, лимитов и контрактов инструментов — только вёрстка панели:

* документ и `#panel` получают высоту фрейма (`html, body { height: 100%; overflow: hidden }`, `main` — flex-колонка);
* единственный скролл-контейнер — новый `#content` (`overflow-y: auto`, `min-height: 0`, `flex: 1 1 auto`);
* `#composer` — последний элемент колонки, **вне** прокрутки, `flex: 0 0 auto`;
* `header` и `#status` — `flex: 0 0 auto` и не вытесняются содержимым;
* у `textarea` — `max-height: 25vh`; общий `max-height`/`overflow: hidden` у композера **убран** по замечанию ревью
  (он мог обрезать собственные контролы), поэтому у `#composer` остался только `margin: 0`;
* `@media (max-width: 300px)` и `@media (prefers-reduced-motion: reduce)` сохранены.

**Важный измеренный факт для следующего шага:** на Astra содержимому остаётся **19 px** высоты: шапка, статус и
композер занимают 480 из 499 px, причём сам композер — 241 px (метка «Запрос» + счётчик байт + textarea 96 px
минимум + ряд кнопок). Формально T2 выполнен, но по существу это тот самый случай, который закрывает
**целевой UX главной панели** (компактный композер без отдельного заголовка, история занимает максимум места).

## 4. Визуальное доказательство (§5 контракта)

* **Windows — есть:** снимок средствами ОС (`.local/sprint6/os-window.png`, `os-panel.png`), потому что кадр
  плагина **не является целью CDP** и в `Page.captureScreenshot` хоста не композитится (проверено: в
  `/json/list` и через `Target.getTargets` только оболочка R7 и страница API).
* **Astra — НЕ получено, и это ограничение среды:** `import -window root` на стенде даёт **249-байтовый пустой**
  PNG (root-окно там не рисуется), а CDP-цели кадра плагина на стенде нет. Геометрия при этом измерена полностью
  (таблица выше). Утверждать визуальное доказательство Astra нельзя.

## 5. Чего этот T2-замер НЕ показывает

* **Визуального состояния Astra** (§4) — только числа.
* Поведения при **ресайзе окна редактора** — не измерялось.
* Реального диалога с моделью: содержимое добавлялось в DOM (это замер вёрстки, а не продуктовый сценарий).
* Что на Astra содержимое остаётся читаемым при 19 px — это, наоборот, **дефект**, зафиксированный выше.

## 7. Ревью и его замечания

Scoped-ревью T2 заблокировало коммит и потребовало: (High) корректного визуального доказательства на обоих
стендах; (High) добора Astra-доказательства — **выполнено** (первая/последняя строка, горизонталь, композер,
«Отправить» — в одном прогоне); (Medium) убрать общий `max-height` у композера — **выполнено**; (Medium) честная
формулировка теста вместо «единственного скроллера» — **выполнено**; (Low) полный порядок корня и покрытие
секций — **выполнено**; (Low) консолидировать противоречивые артефакты — **выполнено** (Astra-проба одна,
Windows-проба дополнена отдельным замером краёв).

Осталось незакрытым **только визуальное доказательство Astra** — по причине §4, то есть ограничение стенда,
а не кода.
