# Каталог инструментов

Каталог пилотной версии `0.9.0-pilot-rc.1`, сверенный с `src/tools`. Пользователь пишет обычное задание; имена ниже выбирает агент, их не нужно вводить как команды в чат.

В исходниках 32 описания: 30 операций с политикой `auto`, отдельная подтверждаемая замена выделения и один отключённый инструмент. Это не обещание доступности всех операций в любом документе: учитываются редактор, режим, возможности SDK, аргументы и лимиты.

- **Чтение (`auto`):** доступно в ASK и EDIT при наличии разрешения чтения.
- **Изменение (`auto`):** доступно в EDIT, исполняется по заданию без отдельного подтверждения.
- **`confirm`:** отдельный путь предпросмотра и применения в панели; модель его не получает в обычном каталоге действий.
- **`deny`:** отключено, агенту не предлагается.

Сохранение файла, shell, произвольный JavaScript и обход ограничений не входят в каталог. [Примеры запросов](examples.md).

## Word — документы

| Инструмент | Режим / политика | Назначение и границы |
|---|---|---|
| `read_selection` | ASK / EDIT · auto | Читает выделенный в редакторе текст. Только чтение, документ не меняет. |
| `read_document_text` | ASK / EDIT · auto | Читает текст документа частями (offset, maxChars) — обзор содержимого. Только чтение. |
| `read_paragraph` | ASK / EDIT · auto | Читает предложение в позиции курсора. Это не чтение всего документа. |
| `find_text` | ASK / EDIT · auto | Ищет строку в документе и возвращает совпадения; 0 совпадений — это ok, а не ошибка. |
| `read_structure` | ASK / EDIT · auto | Читает структуру документа: заголовки и таблицы. Аргументов не принимает. |
| `read_context` | Отключён · deny | Читает фрагмент по адресу scope/index. Политика deny: модель его не получает. |
| `insert_paragraph` | EDIT · auto | Вставляет у КУРСОРА. position:end добавляет перевод строки, НЕ выбирает конец/раздел. Для адресной правки — replace_text; для конца — insert_blocks. |
| `insert_blocks` | EDIT · auto | Блоки в конец; afterParagraphText — после единственного абзаца с этим точным текстом. heading — заголовок. Списки: «1. »/«• » в text. |
| `insert_table` | EDIT · auto | Вставляет таблицу из матрицы строк data. Стилей и строки заголовка не применяет. |
| `set_heading` | EDIT · auto | Превращает СУЩЕСТВУЮЩИЙ абзац (по индексу paragraph) в заголовок уровня level. Текст не вставляет. |
| `replace_selection` | EDIT · confirm | Заменяет текущее выделение на text; запись — только после подтверждения в панели (предпросмотр, затем Apply). |
| `format_range` | EDIT · auto | Оформляет [start, end) абзаца: end не включён. align, bold, italic, underline, strikeout. Только включает свойства. |
| `add_hyperlink` | EDIT · auto | Добавляет гиперссылку url с текстом text — в конец документа или в абзац paragraph. |
| `replace_text` | EDIT · auto | Заменяет вхождения search на replace во всём документе (replace: "" — удаление). Курсор и выделение не читает. |
| `insert_image` | EDIT · auto | Вставляет картинку dataUrl размерами widthPx×heightPx — в конец документа или в абзац paragraph. |
| `insert_comment` | EDIT · auto | Добавляет комментарий с текстом text. Текст документа больше нигде не меняет. |

[Схемы аргументов и реализация](../src/tools/word.js).

## Cell — таблицы

| Инструмент | Режим / политика | Назначение и границы |
|---|---|---|
| `read_sheet` | ASK / EDIT · auto | Читает активный лист: имя, номер, число листов, значения и формулы использованного диапазона. |
| `read_range` | ASK / EDIT · auto | Читает диапазон: address — диапазон (A1 или A1:C10), значения и формулы. sheet — имя листа, sheetIndex — индекс; без них активный. |
| `write_range` | EDIT · auto | Пишет блок: address — адрес (совпадает с блоком), cells — строки (числа строкой, формулы с «=»). sheet — имя листа, sheetIndex — индекс; без них активный. |
| `rename_sheet` | EDIT · auto | Переименовывает лист: newName — новое имя (до 31 символа), sheet — имя источника, sheetIndex — его индекс; без них активный. |
| `add_sheet` | EDIT · auto | Добавляет лист в конец книги: name — имя (необязательно; фактическое читается из редактора). |
| `list_sheets` | ASK / EDIT · auto | Перечисляет листы книги: имя, индекс, признак активного и скрытого листа. |
| `format_cells` | EDIT · auto | Форматирует address. columnWidth — ширина в символах, НЕ пикселях (обычно 12–30); rowHeight/fontSize — пункты. sheet/sheetIndex — лист; иначе активный. |

[Схемы аргументов и реализация](../src/tools/cell.js).

## Slide — презентации

| Инструмент | Режим / политика | Назначение и границы |
|---|---|---|
| `read_presentation` | ASK / EDIT · auto | Читает структуру активной презентации: слайды, layout, типы объектов и наличие текста. |
| `read_slide` | ASK / EDIT · auto | Читает текущий слайд или slideIndex: объекты, типы, placeholder и полный текст в лимите. |
| `add_slide` | EDIT · auto | После текущего; layoutFromSlideIndex — лишь макет. Цель — возвращённый slideIndex. В конец: move_slide(slideIndex,slidesCount-1); текст — по новому индексу. |
| `set_slide_text` | EDIT · auto | Заменяет весь текст объекта objectOrdinal на text; slideIndex необязателен и без него выбран текущий слайд. |
| `add_table` | EDIT · auto | Добавляет таблицу columns x rows на slideIndex; slideIndex необязателен. |
| `add_image` | EDIT · auto | Добавляет imageDataUrl на slideIndex с widthEmu и heightEmu; slideIndex необязателен. |
| `duplicate_slide` | EDIT · auto | Дублирует slideIndex в конец презентации с проверкой layout, объектов и текста. |
| `move_slide` | EDIT · auto | Перемещает слайд fromIndex в toIndex и проверяет сохранность остальных слайдов. |
| `format_slide_text` | EDIT · auto | Форматирует objectOrdinal на slideIndex?; задайте bold, italic, underline, fontSize, fontFamily или color {r,g,b}. |

## Как читать каталог

Индексы API слайдов и объектов отсчитываются от нуля; сотрудник может говорить «первый слайд». После перестановки агенту необходимо учитывать новую структуру. Для Cell адреса задаются в A1-нотации; лист выбирается именем или индексом там, где это поддержано схемой.

В Word `read_paragraph` фактически читает предложение у курсора, а не произвольный абзац по номеру. `insert_paragraph` зависит от курсора; для добавления в конец используется `insert_blocks`. Текстовые пункты списка не означают поддержку всех видов автоматической нумерации. `format_range` поддерживает ограниченный набор свойств, а не весь интерфейс оформления Р7.

Наличие операций вставки изображения не означает поиск, генерацию картинок или пользовательскую загрузку файлов через чат: инструменту нужны допустимые данные изображения. PDF-конвертация, произвольное удаление слайдов, SmartArt и полный набор офисных объектов в этом каталоге не заявлены.

Для длинного Word-документа модель может получать профиль `bulk`: `read_structure`, `read_document_text`, `insert_blocks`, `insert_table`, `format_range`. Это подмножество того же реестра.

Проверки фактического результата зависят от операции; не следует приравнивать ответ модели к доказательству качества всего документа. [Ограничения](deployment.md#known-limitations) · [Протокол](ai-protocol.md) · [Реестр и фильтрация](../src/tools/registry.js).
