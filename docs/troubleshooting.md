# Помощь и частые проблемы

Начните с версии плагина и [проверенной конфигурации](deployment.md). Для пилота первая линия поддержки — администратор организации.

| Ситуация | Что проверить и сделать |
|---|---|
| Плагина нет во вкладке «Плагины» | Установлен ли DEB и выполнена ли активация в профиле именно сотрудника. После установки может потребоваться перезапуск Р7; сначала сохраните документы |
| Проверка совместимости отказала | Сравнить полную версию Astra, Р7 и архитектуру с инструкцией. Не обходить preflight и не отключать защиту Astra |
| Не удаётся подключиться | Полный HTTPS URL `/v1/chat/completions`, модель и ключ. Администратору проверить сеть, сертификаты, CORS и авторизацию; не отключать проверку TLS |
| Настройки приходится вводить заново | Проверить учётную запись ОС, версию всех панелей и успешное сохранение профиля. Настройка под отдельной учётной записью администратора не настраивает сотрудника |
| HTTP_ERROR или TIMEOUT | Проверить доступность сервера и ограничения провайдера. Перед повтором задания на изменение проверить, не выполнена ли уже часть действий |
| Ошибка формата ответа | Модель не соблюла протокол. Уточнить запрос; при повторении администратору проверить совместимость модели. Не вставлять исполняемый код из ответа |
| Ответ есть, а изменения нет | Проверить режим EDIT, нужный открытый файл, наличие предпросмотра и сообщения об ошибке. В ASK запись запрещена. Сообщить о воспроизводимом случае, если ассистент заявил успех без результата |
| Задание выполнено частично | Указать невыполненную часть отдельным запросом. Проверить видимый документ, формулы или порядок слайдов; не повторять всё задание вслепую |
| Редактор занят / результат неизвестен | Дождаться завершения команды. Не повторять запись автоматически. Если работа не восстанавливается, сохранить документы средствами Р7 и согласовать с администратором перезапуск |
| После Undo пропал Redo в Slide | Известное ограничение чтения через SDK. Перезапуск потерянную ветку Redo не возвращает; изменения придётся выполнить заново |
| Чат исчез после перезапуска | История хранится в памяти; сохранение подключения не означает сохранение диалога |

## Что означает «Сбросить настройки»

Удаляется подключение продукта, после чего появляется первоначальный экран настройки. Это не откат документа, не восстановление Undo/Redo и не универсальное исправление сетевой ошибки. Для замены ключа используйте обычное [изменение подключения](admin-connection.md).

<a id="report"></a>
## Как сообщить о проблеме

Передайте администратору версию плагина, Astra и Р7; редактор; режим ASK/EDIT; точные шаги на вымышленном примере; ожидаемый и фактический результат; отображённый код ошибки. Прикладывайте только очищенные скриншоты и тестовые файлы.

Пользователь может создать [Issue](https://github.com/blazar-source/r7-ai-assistant/issues). Не прикладывайте ключи, заголовки авторизации, рабочие документы, персональные данные или полный браузерный профиль. Отчёт об уязвимости передавайте по [SECURITY.md](../SECURITY.md). Срок ответа и круглосуточная поддержка для пилота не обещаны.
