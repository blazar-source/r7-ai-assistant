# Stage B local plugin package

This archive is **not** a Pilot RC or Stage B PASS. Sprint 1 implements guarded
Word Preview→Apply, with bounded native mutation/formatting/Undo witnesses.
Composite cross-document/lifecycle/storage/session/TTL acceptance remains open;
see the [current runtime inventory](<../../docs/sprint-1-progress.md>) for measured
scopes and limits. Host implementation or packaging alone is not runtime proof.

## Build and verify (development host only)

```sh
npm ci --ignore-scripts
npm test
npm run audit
npm run build
```

Node 24.21.0 was used for host verification. Acorn 8.15.0 and esbuild 0.25.10
are exact dev-only dependencies, with the platform build binary pinned by the
lockfile. Neither tool is a user runtime dependency. No CDN or runtime downloads.
The existing package version is a prospective label, not acceptance evidence.

[Builder](<../../scripts/build-plugin.mjs>) writes only below ignored `dist/`.
`dist/plugin/r7-ai-assistant.zip` and `dist/plugin/r7-ai-assistant.plugin` are the
same ZIP STORE bytes. Each build also emits the local authored browser source
bundle `panel.js` and release assets there. There is no repository/source-tree
archive, bootstrap Node program, installed SDK copy or source map in the plugin.
No minification or syntax downleveling obscures the inline synchronous
`callCommand(function () { ... })` body. The bundle itself must pass the existing
conservative AST audit before any release output is written.

The release allowlist is exactly:

- `config.json` — byte-for-byte copy of the approved public
  [canonical manifest](<../../src/plugin/config.json>), never user connection settings;
- `index.html`, `styles.css`, `panel.js`;
- `resources/icon.png` (32×32), `resources/icon@2x.png` (64×64);
- `LICENSE`, `THIRD_PARTY_NOTICES.md`.

The original local document/proposal icon is generated by the authored
[asset generator](<../../scripts/icon-assets.mjs>) using Node standard-library PNG
encoding. It uses no SDK art, downloaded images or fonts. All six local UI/manifest
asset paths resolve within the emitted release tree; the SDK is deliberately separate.
The builder does not glob-copy anything. Tests, `.local`, mock infrastructure,
certificates, keys, environment/configuration state and build tooling never enter
this inventory. The ZIP32 writer sorts names by code-point order, uses STORE,
UTF-8 names, 1980-01-01 00:00:00 timestamps, Unix regular-file 0644 modes and no
extras/comments. Identical source, locked tooling and Node/zlib inputs produce
byte-identical archives; dual host builds are tested and SHA-256 compared.

## CSP and lifecycle limits

The local policy denies default resources, inline scripts/styles, objects, base
URL changes and form submission; only local scripts/styles/images and HTTPS
connections are permitted. Editable bank endpoints require `connect-src https:`;
transport independently validates the full URL and refuses redirects.
`script-src 'self' 'unsafe-eval'` is the **trusted installed SDK exception**:
that SDK evaluates editor initialization and serializes static commands. CSP
cannot confine this exception to vendor code in the same frame. The complete
runtime is **not eval-free**. Authored code is separately audited and no
model/document string is ever executed as HTML, Markdown or JavaScript.
Actual CEF origin/CSP behavior is NOT RUN; never loosen TLS or policy to claim PASS.

The bridge is constructed once after standard SDK `init`, using only explicit
`plugin.info.editorType` word/cell/slide; unknown values are not guessed.
Duplicate same-editor init alone preserves unexpired Preview and does not
recreate/bypass a lifetime lease. A different reported editor disposes the old panel and requires
standard platform reload instead of reusing a Word adapter in cell/slide.
Standard package-evidenced `onTargetPositionChanged` and `onDocumentContentReady`
channels invalidate operations. Their completeness for selection/document/editor
changes is **unproven** in target runtime. A visible notice says so. Every analysis
with selected context performs a fresh bounded Word read; the exact text is not
claimed to be a locator, domain classifier or selection-ownership certificate.
Cell/slide reads are explicitly unavailable; disabling context explicitly allows
an ASK without document data. Document text is a separate bounded untrusted user
message, never a system instruction, and is not retained in chat history.

One active operation owns an immutable request snapshot and a total deadline
established before reading context. Late results cannot publish history/status/
preview after invalidation. A timed-out SDK read stays busy/uncertain until its
actual callback releases the old slot. No bridge recreation, queued read or retry.
Previews have a 120-second TTL. Explicit Word Apply rechecks the bridge-owned
target, current public document identity, editor/tracking availability and exact
nonempty selection before dispatch; repeated identity checks and text equality
are not immutable locators or atomic check/write proof. A 15-second observation
deadline and dispatched/uncertain ownership lock exist; only a genuine matching
SDK callback settles the dispatched slot. Stop/dispose cannot undo an accepted
write. Callback acknowledgment is not verified effect, cancellation or rollback.
No controller-fake result here is actual editor guard proof or B mutation PASS.

The key input is masked. All connection fields are editable. Plaintext opt-in
warning remains visible; residual `keyPersistenceWarning` is displayed independently
of opt-in/storage error. Reset touches only the settings namespace and does not
claim failed storage deletion succeeded. Native labels/buttons/forms, polite
live status, visible focus and in-flow responsive layout are authored here;
host DOM-boundary tests are not real CEF visual/keyboard acceptance.
